# 测试产品库

**规则：同一目录下的所有图片都是同一件商品**，只是拍摄角度不同；唯一的例外是 `marble_watch_variants`，它是同一款表的两个颜色款，专门用来测试多款式。每组多图都已逐张目视核对过。

所有图片来自 rawpixel 的公有领域图库，授权为 **CC0**，可以自由使用和分发。每张图的原始页面见对应目录下 `product.json` 的 `sources` 字段。图片统一为 1024px、JPEG 格式。

| 目录 | 商品 | 图数 | 考验什么 |
|---|---|---|---|
| `ceramic_mug` | 手工粗陶马克杯 | 1 | 基准用例：简单商品，只有一张图 |
| `led_sneaker` | 发光 LED 小白鞋 | 2 | 同一款鞋的不同角度、发光鞋底 |
| `headphones` | 折叠式无线头戴耳机 | 2 | 同一款耳机，耳罩上的按键等小细节 |
| `minimal_watch` | 黑色大理石纹极简腕表 | 1 | 表盘纹理、细指针等精细细节 |
| `marble_watch_variants` | 大理石纹极简腕表（黑白双款） | 3 | **多款式**：白色和黑色两种表盘，第 3 张两款同框；考验不写死颜色、不混合两款的特征 |
| `red_hightop_sneaker` | 红色高帮 LED 发光鞋 | 3 | 同一款鞋的 3 个角度（一双、单只、一双），每张灯色不同 |
| `sunglasses` | 经典飞行员墨镜 | 1 | 金属细框、镜片反光 |
| `table_lamp` | 奶油风陶瓷台灯 | 1 | 生活场景竖图，不是白底，需要从场景里认出主体 |
| `backpack` | 轻量户外徒步双肩包 | 1 | 随手拍的角度、软质面料 |
| `car_fragrance` | 复古玻璃瓶车载香氛 | 1 | 透明玻璃 + 带品牌文字的标签（最难） |

`product.json` 的字段：`name`、`category`、`selling_points`（流水线的输入），以及 `images`、`test_focus`、`license`、`sources`。卖点是为了测试编写的，不代表真实商品参数。
